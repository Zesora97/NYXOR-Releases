# NYXOR – Downloads

Trading-Dashboard für Windows. Dieses Repository enthält nur die fertigen
Installer (unter **Releases**), keinen Quellcode und keine Nutzerdaten.

**Installieren:** Unter „Releases“ die neueste `NYXOR-Setup-<Version>.exe`
herunterladen und ausführen. Updates installiert NYXOR danach selbst.

Alle Daten bleiben lokal auf deinem PC.
